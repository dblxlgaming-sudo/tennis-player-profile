# WNBA Player Profile V1

`wnba-player-profile-v1` is a factual, browser-consumable artifact generated by
the WNBA workspace from the canonical database. It is a **tracked sample**, not
a claim of complete season coverage. The top-level `CoverageManifest` and every
aggregate/split state their applicable date range and sample size.

## Identity and joins

`PlayerID` is the only supported downstream player join key. It is the
provider-scoped ESPN ID (`espn:<athlete-id>`). Consumers must not join on
`PlayerName`. `CurrentTeam` contains the existing ESPN and WNBA team IDs where
available. Age, height, jersey number, aliases, and biography claims are absent
because they are not authoritative in this workspace.

## Profile shape

Each `Profiles[]` item contains:

- identity/context: `ProfileVersion`, `GeneratedAt`, `PlayerID`, `ESPNPlayerID`, `PlayerName`,
  `CurrentTeam`, `Position`, `ActiveRoster`, `HeadshotURL`;
- coverage: `TrackedDateStart`, `TrackedDateEnd`, `GamesPlayed`;
- `Overall` plus factual `Splits` for `L5`, `L10`, `Home`, `Away`, `Starter`,
  and `Bench`;
- chronological `RecentGames` (the latest ten tracked played games, oldest to
  newest); and
- `DataProvenance`.

Every summary includes `GamesPlayed`, `TrackedDateStart`, and `TrackedDateEnd`.
`Performance` includes Minutes, Points, Rebounds, Assists, and Turnovers.
`Shooting` includes aggregate FieldGoals, ThreePointers, FreeThrows, and
PointsPerMinute. `Playmaking` includes Assists, Turnovers, and
AssistTurnoverRatio. `Rebounding` includes offensive, defensive, and total
rebounds. `Defense` includes steals and blocks.

Metric objects include `Total`, `PerGame`, and `ObservedGames`. Shooting
percentage objects include `Makes`, `Attempts`, `Percentage`, and
`ObservedGames`. Percentages are aggregate makes divided by aggregate attempts;
individual-game percentages are never averaged.

## Played-game and missing-value rules

A played game is a `player_game_logs` row not explicitly marked `did_not_play`.
DNPs never enter `GamesPlayed`, L5, L10, or RecentGames. Rows are ordered by
`game_date`, then `game_id`; L5/L10 take the actual latest played rows without
substituting an older row because an optional statistic is missing.

Missing factual values remain JSON `null`. They are never converted to zero.
Totals and per-game values report `ObservedGames` so partial optional-stat
coverage cannot be mistaken for a complete sample. `HomeAway`, score, and W/L
remain null if their source is unavailable.

## Explicit exclusions

This artifact contains no projections, odds, market lines, probabilities,
edges, hit rates, grading, Candidate/Lean/Pass labels, LBG data, or Player Stat
Chart calculations. It is a read-only factual profile handoff.
